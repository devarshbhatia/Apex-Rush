# Apex Rush

## gstack-game

gstack-game is installed at `.claude/skills/gstack-game` (project) and `~/.claude/skills/gstack-game` (global). Available skills:

- `/triage` — route a game problem to the right skill
- `/spark-lens` — quick lens on an idea or concept
- `/game-import` — import an existing game/project for review
- `/game-ideation` — generate and refine game ideas
- `/game-direction` — set vision, pillars and direction
- `/game-review` — overall game design review
- `/game-eng-review` — engineering/architecture review
- `/balance-review` — economy, difficulty and balance review
- `/player-experience` — player journey and experience review
- `/game-ux-review` — UI/UX review
- `/plan-design-review` — review a design plan
- `/pitch-review` — review a pitch
- `/prototype-slice-plan` — plan a vertical-slice prototype
- `/implementation-handoff` — spec handoff to implementation
- `/gameplay-implementation-review` — check gameplay code vs. design
- `/feel-pass` — game feel / juice pass
- `/build-playability-review` — is the current build playable
- `/game-qa` — QA the game
- `/game-ship` — release checklist and shipping
- `/game-debug` — debug gameplay issues
- `/game-retro` — retrospective
- `/game-codex` — second-opinion review
- `/game-docs` — game documentation
- `/game-visual-qa` — visual QA
- `/asset-review` — art/audio asset review
- `/playtest` — playtest planning and analysis
- `/careful` — warn before destructive actions
- `/guard` — restrict edits to a safe scope
- `/unfreeze` — lift a `/guard` restriction
